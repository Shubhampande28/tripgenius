# City Expansion Backlog: 200 Missing Tourist Destinations

Prepared: 24 July 2026

## Selection method

This is a curated expansion backlog, not a claim that one ranking contains all 200
destinations. It combines signals from Euromonitor's Top 100 City Destinations,
Resonance's World's Best Cities, Tripadvisor's destination awards, UN Tourism data
reported by the OECD, and obvious regional gaps in the current TripGenius catalog.

Every destination below was checked against the current 303-guide inventory. The
ordering balances visitor importance, geographic coverage, and usefulness as a
travel-planning destination. Each implementation batch contains exactly ten guides.

## Delivery rule

Implement one numbered batch at a time. A batch is complete only when its ten city
guides, required country hubs, navigation relationships, metadata, and generated
content pass the same parity checks as the existing catalog. Maps may remain in the
approved “yet to come” state until verified coordinates are added.
